# PCL2-theme-crack

**如影响作者或后续PCL2恢复正常，本项目将立即删除，如果可以的话还请支持原作者，谢谢！**

在PCL暂停更新后通过插件恢复主题选择，并添加自定义配色、遮罩选择等功能


主要修改内容：

标题栏可用自选背景图，支持高斯模糊、亮度、着色透明度；双色（1/2）/三色（1/3）混合 + 渐变过渡；可叠加原版 10 种遮罩纹理

CurseForge / Modrinth 可切换/自定义镜像服务器，避免单一镜像失效后无法下载


移除的内容：

屏蔽手动检查更新、自动更新与服务端下发的静默更新；跳过服务器公告弹窗及其附带动作；帮助页不再显示"反馈""新功能投票"入口



本项目是基于[Plain Craft Launcher 2](https://github.com/Meloong-Git/PCL) 的二次创作，由AI工具辅助制作
